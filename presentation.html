01 — Introduction

Why LinguaCast?

The Challenge

  • Communication across languages remains a barrier.
  • Existing tools are mostly text-based — slow and awkward.
  • Voice translation usually requires paid APIs.
  • Backend setups add complexity for simple projects.
  • Many solutions do not support Tamil or Indian languages.

Our Solution

  • 100% browser-native — no server needed.
  • Uses the Web Speech API for both recognition and synthesis.
  • Free translation endpoint — zero cost.
  • Supports 30 languages including Tamil, Hindi, Telugu.
  • Modern UI with dark/light themes and persistent history.
02 — Problem Statement

Five Core Problems

⌨️

Text-Only Input

Users must type queries. Real conversations become slow and unnatural.

🔇

No Voice Output

Most tools display text but never speak it, limiting accessibility and usability.

💸

Expensive APIs

Google Cloud, DeepL, Azure all require paid accounts for production.

⚙️

Complex Setup

Backend, API keys, and environment variables make simple projects hard.

🌐

Language Gaps

Many tools lack reliable support for Indian regional languages like Tamil.

03 — Objectives

What We Set Out To Build

#Objective
1Build a fully client-side voice translator with zero backend.

3Provide both text output and audio output.
4Implement echo guard to prevent the mic from re-capturing TTS.
5Persist translation history across sessions.
6Deliver a modern, responsive, theme-able UI.
7Guarantee zero cost — no API keys, no subscriptions.

09 — Algorithm

Core Pseudocode

// Main translation flow FUNCTION onSpeechResult(event): IF echoGuard AND (agentSpeaking OR cooldownActive): RETURN FOR each result in event.results: IF result.isFinal: finalTranscript += result.transcript IF finalTranscript has new content: DEBOUNCE 600ms → translateText(finalTranscript) UPDATE originalText panel FUNCTION translateText(text): IF not online: RETURN error from = sourceLang.code; to = targetLang.code IF from == to: RETURN text url = "https://translate.googleapis.com/translate_a/single?..." response = FETCH(url) translated = parse(response) UPDATE translatedText panel SAVE to history IF autoPlay: speakTranslation() FUNCTION speakTranslation(): IF echoGuard: recognition.stop() agentSpeaking = TRUE utter = new SpeechSynthesisUtterance(translation) utter.onend = () => { agentSpeaking = FALSE cooldownTimer = setTimeout(1400ms) } speechSynthesis.speak(utter)

17 — Limitations

Known Limitations

🌐

Browser Support

Best in Chrome & Edge. Firefox and Safari have limited Speech Recognition support.

📡

Internet Required

Translation uses a remote endpoint — no offline mode yet.

🎭

No Voice Cloning

Output uses a robotic browser voice, not the speaker's tone.

👥

No Speaker Diarization

Cannot distinguish between multiple speakers in a conversation.

⏱️

~1.5s Latency

Speech → text → API → translation → display takes a moment.

📝

No Custom Glossary

Users cannot override translations for specific terms.
